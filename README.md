# Hospital Controller (ROS 2)

Hospital Controller simulates a hospital environment for the Healthcare
Challenge at RoboCup 2027, with ROS 2 interfaces, simulated robots, and an
RViz visualization.

**Maintenance notice:** Siemens Healthineers will not maintain this project.
Issues, contributions, and security reports are not guaranteed to receive a
response or updates.

See the [main project guide](src/hospital_bringup/README.md) for requirements,
build and launch instructions, and package documentation.

For project contacts and community expectations, see
[Maintainer.md](Maintainer.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
To contribute, see [CONTRIBUTING.md](CONTRIBUTING.md). To report a security

records project packages plus the installed versions of their direct APT
dependencies
